# Промпты для сессий Claude Code (Sonnet)

## Как пользоваться

1. Открой новую сессию Claude Code на этом репозитории.
2. Выбери модель Sonnet и уровень рассуждений из задачи в `ROADMAP.md` (`medium` или `high`).
3. Вставь **общий префикс** и промпт задачи.
4. Когда Claude закончит — проверь по «Приёмке» в `ROADMAP.md`. Если менялся Apps Script — сделай «Как развернуть» из его отчёта.
5. Замечания пиши в ту же сессию. Новую задачу лучше начинать в новой сессии.

**Когда брать `high`:** задачи с логикой и краевыми случаями (заказы, валидация, кэш, корзина). **`medium`:** вёрстка, тексты, контент, простые скрипты. Если на `medium` результат сыроват — повтори на `high`.

## Общий префикс (вставлять в начало каждого промпта)

```
Прочитай CLAUDE.md и ROADMAP.md. Выполни задачу ниже строго в рамках её критериев приёмки.
Документы проекта лежат в docs/ — читай те, что указаны в задаче, и следуй им как спецификации.
Если спецификация противоречива или чего-то не хватает — выбери самый простой вариант,
запиши решение в docs/decisions.md и упомяни в отчёте.
Команды запускай сам, я командной строкой не пользуюсь. В конце: тесты, коммит, пуш,
отметка [x] в ROADMAP.md, отчёт по-русски: что сделано, как проверить в браузере,
и «Как развернуть», если менялся apps-script/.
```
