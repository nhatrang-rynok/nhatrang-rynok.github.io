# Контракт API: сайт ↔ Apps Script

Базовый URL — адрес веб-приложения Apps Script (`https://script.google.com/macros/s/<DEPLOYMENT_ID>/exec`). Хранится в `site/config.js` как `API_URL`. Пустая строка — режим заглушки.

Все ответы — JSON (`ContentService`, MIME `application/json`). Apps Script всегда отвечает HTTP 200 (по-другому он не умеет), поэтому успех определяется полем `ok`.

## GET `?action=catalog`

Публичный каталог.

```json
{
  "ok": true,
  "version": "2026-10-10T14:03:22Z#a1b2c3",
  "generatedAt": "2026-10-10T14:03:22Z",
  "settings": {
    "site_title": "Рынок у отеля",
    "phone": "+84 000 000 000",
    "whatsapp": "84000000000",
    "telegram": "primer_operator",
    "orders_enabled": true,
    "announcement": "",
    "terms": "",
    "done_text": "С вами свяжутся по поводу заказа на оставленный контактный телефон. Ожидайте."
  },
  "categories": [
    { "id": "fruits", "name": "Фрукты", "icon": "🥭", "note": "", "sort": 1 }
  ],
  "products": [
    {
      "id": "fr-001",
      "cat": "fruits",
      "name": "Манго",
      "short": "Сладкое, спелое",
      "desc": "…",
      "price": 90,
      "unit": "кг",
      "step": 0.5,
      "min": 1,
      "img": "https://lh3.googleusercontent.com/d/FILE_ID",
      "warn": "Сок и кожура могут вызвать раздражение кожи…",
      "src": "Рынок Чо Дам",
      "adult": false,
      "stock": "in",
      "rel": ["fr-002", "sw-001"],
      "sort": 10
    }
  ],
  "popular": ["fr-001", "al-002"]
}
```

Правила:
- `version` меняется при любом изменении данных (время сборки + короткий хэш содержимого).
- `img` — базовая ссылка **без** суффикса размера, сайт добавляет `=w400` / `=w900` сам. Пусто — сайт показывает заглушку.
- `stock`: `in` | `preorder` | `out`. Товары с `out` отдаются (показываем серыми), выключенные (`Показывать` снят) — не отдаются.
- `popular` — ID в порядке показа: сначала «Хит», потом по статистике за `popular_days`, всего не больше `popular_count`. Только товары со `stock` ≠ `out`.
- `whatsapp` отдаётся уже очищенным (только цифры) — для ссылок `https://wa.me/<цифры>`.
- Ошибка: `{ "ok": false, "error": "SERVER", "message": "…" }`.

`site/data/catalog.sample.json` должен строго соответствовать этому формату. Тест `tests/sample-catalog.test.js` это проверяет.

## POST — заказ

Запрос: `Content-Type: text/plain;charset=utf-8` (не `application/json` — иначе браузер отправит preflight, который Apps Script не обрабатывает). Тело — JSON:

```json
{
  "action": "order",
  "clientOrderId": "c0f7e6a2-1b3c-4d5e-9f00-123456789abc",
  "phone": "+7 (999) 000-00-00",
  "messenger": "whatsapp",
  "name": "Ольга",
  "room": "512",
  "comment": "Манго поспелее",
  "adultConfirmed": true,
  "items": [
    { "id": "fr-001", "qty": 2 },
    { "id": "al-002", "qty": 1 }
  ],
  "clientTotal": 830,
  "catalogVersion": "2026-10-10T14:03:22Z#a1b2c3",
  "website": ""
}
```

- `messenger`: `whatsapp` | `telegram` | `call`.
- `website` — поле-ловушка. Если не пустое, сервер отвечает **успехом** с фиктивным номером и ничего не сохраняет.
- `clientTotal` и `catalogVersion` — только для диагностики, сервер их не использует для расчёта.

### Ответ: успех

```json
{ "ok": true, "orderNo": "N-0042", "total": 830, "duplicate": false }
```

`duplicate: true` — такой `clientOrderId` уже был, возвращён прежний номер.

### Ответ: ошибка

```json
{
  "ok": false,
  "error": "ITEM_UNAVAILABLE",
  "message": "Некоторые товары сейчас недоступны",
  "fields": {},
  "items": ["fr-003"]
}
```

| `error` | Когда | Что делает сайт |
|---|---|---|
| `VALIDATION` | Неверный телефон, слишком длинные поля, пустая корзина, нет галочки 18+, неверное количество | Подсвечивает поля из `fields` (`{"phone": "Проверьте номер"}`) |
| `ITEM_UNAVAILABLE` | Товара нет, он выключен или `stock = out` | Убирает `items` из корзины, показывает, что именно убрано, предлагает отправить снова |
| `ORDERS_PAUSED` | `orders_enabled` = выкл | Показывает объявление и кнопки связи |
| `RATE_LIMIT` | Превышены лимиты | «Слишком много заказов подряд. Напишите нам в WhatsApp» + кнопка |
| `SERVER` | Всё остальное | Экран ошибки с «Повторить» и «Отправить через WhatsApp» |

Сетевая ошибка или таймаут (15 с) обрабатываются как `SERVER`. При повторе отправляется **тот же** `clientOrderId`.

### Серверная валидация

- `phone`: убрать всё, кроме цифр и ведущего `+`; `8XXXXXXXXXX` (11 цифр, начинается с 8) → `+7XXXXXXXXXX`; без `+` → добавить `+`; итог `^\+\d{9,15}$`.
- На сайте проверка телефона чуть строже: 10 цифр, начиная с 9, без «+» (российский номер без кода страны) не принимается с подсказкой «Добавьте код страны». Сервер в T2.1 лучше сделать так же. Префикс `00` (международный) заменяется на «+».
- Поле-ловушка в форме называется `hp-check` (не `website`, чтобы автозаполнение браузера его не трогало), а в запрос уходит как `website`.
- `name` ≤ 50, `room` ≤ 10, `comment` ≤ 500 символов. Управляющие символы вырезать.
- `items`: от 1 до 50 позиций, ID уникальны (дубли складываются), `qty` — число > 0, ≤ 100, кратное `step` (погрешность 1e-9), ≥ `min`.
- Если есть товар `adult` → нужен `adultConfirmed === true`.
- Сумма = Σ (цена ₽ из таблицы × qty), округлить до целых рублей.

## GET `?action=ping`

`{ "ok": true, "time": "…" }` — проверка, что развертывание живо. Используется в инструкции по развертыванию.
