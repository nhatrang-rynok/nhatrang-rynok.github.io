# Выбор стека

**Решение принято:** вариант А — статический сайт + Google Таблица + Apps Script. Ниже — почему, и с чем сравнивали.

## Критерии

1. Саня сам добавляет товары и цены с телефона.
2. Сайт быстро открывается на мобильном.
3. Минимум платных сервисов (в идеале 0 ₽).
4. Заказ приходит Сане в Telegram (или WhatsApp).
5. Владелец уже умеет работать с Apps Script и Таблицами, CLI не хочет.

## Сравнение

| | А. Статика + Таблица + Apps Script | Б. Небольшой backend с админкой | В. Всё на Apps Script (HtmlService) |
|---|---|---|---|
| Правка товаров с телефона | Приложение Google Таблицы — Саня уже умеет | Нужно делать админку | Приложение Google Таблицы |
| Скорость сайта | Статика с CDN — быстро. Каталог из кэша браузера, обновление в фоне | Быстро | Медленно: холодный старт 1–3 с, сайт во фрейме |
| Стоимость | 0 ₽ | VPS или PaaS — от ~5 $/мес, плюс поддержка | 0 ₽ |
| Уведомления | Telegram Bot API через UrlFetchApp | Любые | Telegram Bot API |
| Адрес сайта | Любой (GitHub Pages, свой домен) | Любой | `script.google.com/macros/s/AKfy…/exec` — длинный, с плашкой Google «приложение создано другим пользователем» |
| Поддержка | Почти не нужна | Обновления, бэкапы, безопасность | Почти не нужна |
| Риски | Лимиты Apps Script (с запасом хватает), холодный старт API | Сервер, деньги, время | Уродливый URL, iframe, медленно |

## Почему А

- Ноль затрат и ноль серверов.
- Таблица и есть админка: Саня правит её с телефона, владелец видит всё.
- Сайт отдаётся как статика — открывается мгновенно, даже если Apps Script думает.
- Лимиты бесплатного аккаунта Google с запасом покрывают сотни заказов в день: UrlFetch — 20 000 вызовов в сутки, время работы скрипта — 6 мин на вызов, одновременных запусков — до 30.

## Минусы А и как их закрываем

| Минус | Что делаем |
|---|---|
| Ответ Apps Script бывает медленным (1–3 с) | Каталог кэшируется в браузере (показываем сразу, обновляем в фоне) и на сервере в CacheService |
| Таблицу легко сломать (удалить колонку, вписать текст вместо цены) | Сервер ищет колонки по заголовкам, а не по номерам. Битые строки пропускает и пишет в лист «Ошибки». В таблице — проверка данных и выпадающие списки |
| Фото с Google Диска как картинки на сайте — неофициальный приём | Ссылки вида `lh3.googleusercontent.com/d/<id>=w600`. Если перестанут работать — запасной план в `03-architecture.md` |
| Код Apps Script разворачивается вручную | Подробная инструкция (`08-deploy-apps-script.md`). Claude к каждому изменению пишет «Как развернуть» |
| Telegram-бот не умеет писать в WhatsApp | Уведомления Сане идут в Telegram. В сообщении — кнопки-ссылки «Написать гостю в WhatsApp» и «… в Telegram». WhatsApp Business API платный и сложный — не берём |

## Технологии

- **Сайт:** HTML + CSS + ванильный JS (ES-модули), без сборки и npm. Хостинг — GitHub Pages, деплой через GitHub Actions.
- **Бэкенд:** Google Apps Script (V8), веб-приложение (`doGet` / `doPost`), скрипт привязан к таблице.
- **Данные:** Google Таблица (каталог, заказы, настройки), Google Диск (фото).
- **Уведомления:** Telegram Bot API, запасной канал — письмо на почту (MailApp, лимит 100 писем в сутки).
- **Тесты:** `node --test` для чистой логики, Playwright (Chromium уже есть в облачной среде) для проверки вёрстки.
