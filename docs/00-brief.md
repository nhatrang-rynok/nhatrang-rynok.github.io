# Бриф (актуальная версия)

Исходный текст без изменений лежит в `00-brief-original.md`. Здесь — то же самое, но с учётом ответов владельца от 10.10.2026.

## Контекст

- **Владелец и разработчик:** программист (Python, ML/CV), раньше делал приложения на Google Apps Script, Таблицах и Диске. Командной строкой не пользуется, работает только в графическом интерфейсе.
- **Партнёр (Саня):** живёт в Нячанге, аниматор в отеле, гражданин РФ. Давно покупает гостям товары на рынке с наценкой. Хороший фотограф.
- **Гости:** русскоязычные отдыхающие, часто 40–50+ лет. В отеле до ~300 человек, после открытия нового корпуса будет больше.

## Суть сервиса

Онлайн-рынок: каталог товаров с рынка и из аптеки с доставкой в отель.

1. Гость открывает сайт с телефона и листает разделы: фото, описание, цена.
2. Добавляет товары в корзину.
3. В корзине видит блок «Возможно, будет интересно».
4. Нажимает «Оставить заказ» и вводит телефон (имя, номер комнаты и комментарий — по желанию).
5. Видит: «С вами свяжутся по поводу заказа на оставленный контактный телефон. Ожидайте».
6. Саня получает уведомление, пишет гостю в WhatsApp или Telegram, закупает и привозит.

## Принятые решения (сводка, подробнее — `decisions.md`)

| Вопрос | Решение |
|---|---|
| Стек | Статический сайт + Google Таблица + Google Apps Script (окончательно) |
| Валюта на сайте | Рубли, со знаком «≈». Саня может вводить цену в донгах, тогда пересчёт идёт по курсу из настроек |
| Контакты | Телефон, WhatsApp, Telegram. Пока заглушки: `+84 000 000 000`, `@primer_operator` |
| Стоимость доставки, минимальный заказ | На сайте не показываем. В настройках есть необязательный текст «Условия», по умолчанию пустой |
| Отзывы | Не делаем совсем (ни от посетителей, ни скриншотами) |
| Лекарства и БАДы | Можно. Это обычные безрецептурные товары из нормальной аптеки. В карточке показываем «Где куплено: аптека …», чтобы гость видел, что товар из надёжного места. Категория запускается после основных |
| Популярные позиции и объёмы заказов | На этапе разработки не важны. Каталог MVP — на заглушках |
| Адрес сайта | Без ника владельца на GitHub, см. `09-hosting-and-url.md` |
| Кто разворачивает | Сайт публикует Claude через GitHub Actions. Apps Script владелец разворачивает сам по инструкции |

## Категории и очередь запуска

1. Фрукты и алкоголь (ром и его варианты) — MVP.
2. Сладости (желейные конфеты, сухофрукты в шоколаде и т. д.).
3. Кофе, сувениры.
4. Аптека: мази, кремы, таблетки, капсулы, БАДы (артишок и т. п.) — только обычные безрецептурные из аптеки.

## Не делаем

Оплату на сайте, регистрацию и личные кабинеты, отзывы, оценки и рейтинги, поддержку Max, обмен валют, экскурсии, трансферы, SIM, аренду, афишу, платную карту. Бесплатная карта (рынок, ТЦ, банкомат) — возможно, позже.
