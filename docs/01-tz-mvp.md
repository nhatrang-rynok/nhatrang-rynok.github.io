# ТЗ на MVP

## Цель

Гость за 2–3 минуты с телефона собирает заказ из каталога и оставляет контакт. Саня через несколько секунд получает заказ в Telegram и видит его строкой в Google Таблице. Саня сам меняет товары, цены и фото с телефона, без программиста.

## Пользователи

| Роль | Что делает | Где |
|---|---|---|
| Гость | Смотрит каталог, собирает корзину, оставляет заказ | Сайт в мобильном браузере |
| Оператор (Саня) | Ведёт каталог, получает и обрабатывает заказы | Google Таблица (приложение на телефоне), Telegram |
| Владелец | Разворачивает, настраивает, следит | Google Таблица, редактор Apps Script, GitHub |

## Экраны сайта

| # | Экран | Что на нём |
|---|---|---|
| 1 | Главная | Название, объявление (если задано), плитки категорий, блок «Самое популярное», кнопки связи (WhatsApp, Telegram; «Позвонить» убрали по решению владельца, D80) |
| 2 | Категория | Карточки товаров: фото, название, цена ≈ ₽ за единицу, кнопка «В корзину», которая после нажатия превращается в «− 1 +» |
| 3 | Товар | Большое фото, название, цена и единица, описание, «Где куплено», предупреждения (плашка), отметка 18+, количество, блок «Вам может понравиться» |
| 4 | Корзина | Позиции с количеством, удаление, итого ≈ ₽, пометка «цены ориентировочные», блок «Возможно, будет интересно», кнопка «Оставить заказ» |
| 5 | Оформление | Форма (поля ниже), краткий состав заказа, кнопка «Отправить заказ» |
| 6 | Готово | «Заказ № N-0042 принят. С вами свяжутся по поводу заказа на оставленный контактный телефон. Ожидайте.» + кнопка «Вернуться в каталог» |
| — | Нижняя панель | Закреплена внизу на всех экранах, кроме оформления, если корзина не пустая: «Корзина · 3 товара · ≈ 2 450 ₽» |
| — | Ошибка отправки | Текст ошибки + «Попробовать ещё раз» + «Отправить заказ через WhatsApp» (с готовым текстом заказа) |
| — | Заказы на паузе | Если в настройках выключен приём заказов: объявление на главной, кнопка «Оставить заказ» заменяется текстом и кнопками связи |

## Поля формы заказа

| Поле | Обязательно | Правила |
|---|---|---|
| Телефон | Да | Международный формат. Подсказка «+7 … или +84 …». После очистки от пробелов и скобок — от 9 до 15 цифр с ведущим `+` |
| Как с вами связаться | Да, по умолчанию WhatsApp | WhatsApp / Telegram / Звонок |
| Имя | Нет | До 50 символов |
| Номер комнаты | Нет | До 10 символов |
| Комментарий | Нет | До 500 символов. Подсказка: «Например: когда удобно получить, спелость фруктов, дата выезда» |
| «Мне есть 18 лет» | Да, если в корзине есть товар 18+ | Галочка |
| Согласие | Нет, только текст | «Нажимая кнопку, вы соглашаетесь, что оператор свяжется с вами по указанному номеру. Телефон используется только для этого заказа» |
| Скрытое поле-ловушка | — | Невидимое поле для ботов. Если заполнено — заказ тихо отклоняется |

## Сценарии

**С1. Обычный заказ.** Главная → категория «Фрукты» → «В корзину» ×3 → нижняя панель → корзина → «Оставить заказ» → телефон → «Отправить» → экран «Готово». В таблице появилась строка заказа, Сане пришло сообщение в Telegram со ссылками «Написать в WhatsApp» и «Написать в Telegram».

**С2. Товар закончился, пока гость выбирал.** Сервер отвечает, что товар недоступен. Сайт убирает его из корзины, показывает «Товар „Манго“ сейчас недоступен, мы убрали его из корзины» и предлагает отправить заказ снова.

**С3. Нет связи.** Отправка не удалась → «Не получилось отправить» → «Попробовать ещё раз» или «Отправить через WhatsApp» (откроется WhatsApp с готовым текстом заказа на номер оператора).

**С4. Двойное нажатие или повторная отправка.** У заказа есть клиентский ID. Сервер не создаёт дубль и возвращает тот же номер заказа.

**С5. Саня меняет цену.** Правит ячейку в таблице с телефона → сайт показывает новую цену не позже чем через 5 минут (кэш). Есть пункт меню «Обновить сайт сейчас».

**С6. Саня добавляет товар.** Новая строка в таблице + фото в папку на Диске с именем `<id>.jpg` → пункт меню «Подтянуть фото» (или автоматически по расписанию) → товар на сайте.

**С7. Саня занят или уехал.** В «Настройках» ставит «Приём заказов» = выкл → на сайте объявление, отправка заказов недоступна, каталог виден.

## Нефункциональные требования

- Первый показ главной на мобильном 4G — до 2 с при повторном визите (каталог из кэша), до 4 с при первом.
- Работает в Safari на iOS 15+ и в Chrome на Android 9+.
- Шрифт ≥ 17–18 px, кнопки ≥ 48 px, никаких иконок без подписи для ключевых действий.
- Стоимость — 0 ₽ в месяц (бесплатные лимиты Google и GitHub). Опционально — свой домен.
- Секреты не хранятся в публичном репозитории.

## Что не делаем в MVP

Оплату, регистрацию и личный кабинет, отзывы и оценки, «Новинки», поиск (появится на этапе 4), несколько фото у товара (этап 4), историю заказов для гостя, мультиязычность, карту, аналитику, поддержку Max.

## Вопросы, без которых нельзя начинать

С учётом ответов владельца блокирующих вопросов для разработки нет: всё, что не решено, закрыто заглушками. **Перед запуском на реальных гостях** нужно закрыть:

1. Реальные номера WhatsApp и Telegram оператора (сейчас заглушки).
2. Кому приходят уведомления в Telegram: только Сане или ещё владельцу.
3. Не против ли отель (правила, коллеги). Можно ли спрашивать номер комнаты.
4. Алкоголь: нужна ли лицензия на доставку (вьетнамский юрист). Пока на сайте 18+ и пометка «только для совершеннолетних».
5. Может ли Саня зарабатывать на стороне по условиям контракта и разрешения на работу.

Список ведётся в `open-questions.md`.
