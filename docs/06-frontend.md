# Спецификация сайта (`site/`)

## Принципы

- Одна страница `index.html`, экраны переключаются по hash-маршрутам.
- Ванильный JS (ES-модули, `<script type="module">`), без сборки и зависимостей.
- Сначала мобильная версия: макет рассчитан на 360–430 px. На десктопе — колонка шириной не больше 640 px по центру.
- Аудитория 40–50+, солнце, лежак: крупно, контрастно, просто.

## Маршруты

| Hash | Экран |
|---|---|
| `#/` или пусто | Главная |
| `#/c/<catId>` | Категория |
| `#/p/<productId>` | Товар |
| `#/cart` | Корзина |
| `#/checkout` | Оформление |
| `#/done/<orderNo>` | Готово |
| неизвестный | Главная |

Кнопка «Назад» в шапке использует `history.back()`. Если истории нет (открыли по ссылке) — ведёт на главную. При смене экрана — прокрутка наверх, при возврате к списку — восстановление прокрутки (запоминать `scrollY` по маршруту).

## Дизайн-основа

- Шрифт: системный (`-apple-system, system-ui, Roboto, sans-serif`). Без веб-шрифтов — экономим трафик.
- Размеры: основной текст 18 px, второстепенный 16 px (не меньше), заголовки 22–26 px, цена 20 px жирным.
- Зоны нажатия ≥ 48×48 px, между кнопками ≥ 8 px.
- Цвета (CSS-переменные в `:root`): светлый фон `#FFFDF8`, текст `#1F1F1F`, акцент (кнопки) — насыщенный зелёный `#1E7A46` с белым текстом, предупреждения — плашка `#FFF4D6` с рамкой `#E0B000`, отметка 18+ — тёмно-красная `#B3261E`. Контраст не ниже AA. Тёмную тему в MVP не делаем (на солнце светлая читается лучше).
- Карточки: скругление 12 px, мягкая тень, фото 1:1 сверху.
- Иконки — инлайновые SVG или эмодзи. Ключевые действия всегда подписаны текстом.
- Анимации — короткие (≤ 200 мс), учитывать `prefers-reduced-motion`.

## Экраны

### Шапка (на всех экранах)
Слева «←» (кроме главной), по центру `site_title`, справа иконка корзины со счётчиком. Шапка закреплена сверху и не выше 56 px.

### Главная
1. Объявление `announcement` (если не пустое) — жёлтая плашка.
2. Если `orders_enabled = false` — красноватая плашка «Сейчас заказы не принимаются. Напишите нам:» + кнопки связи.
3. Плитки категорий: сетка 2 колонки, большая иконка-эмодзи и название. Только категории, в которых есть хотя бы один товар.
4. «Самое популярное» — горизонтальная лента карточек (scroll-snap), если в `popular` есть товары.
5. «Как это работает» — 3 коротких пункта: «Выберите товары → Оставьте телефон → Мы напишем, купим и привезём в отель».
6. `terms`, если задан.
7. Подвал: кнопки «WhatsApp», «Telegram», «Позвонить» (`https://wa.me/<цифры>`, `https://t.me/<ник>`, `tel:<номер>`).

### Категория
Заголовок + `note`. Список карточек в одну колонку (на ширине ≥ 600 px — две). Карточка:
фото слева 96–112 px (или сверху — выбрать на этапе 1, проверить скриншотами), название, `short`, цена «≈ 290 ₽ / кг», отметка 18+, отметка «Под заказ»; справа или снизу кнопка «В корзину». После добавления кнопка превращается в степпер «− 1 кг +». `stock = out` → карточка серая, вместо кнопки «Сезон закончился».

Нажатие на карточку (кроме кнопок) открывает товар.

### Товар
Фото на всю ширину (1:1, `=w900`), название, цена и единица, степпер + «В корзину». Дальше: `desc`; «Где куплено: …»; плашка предупреждения (`warn`) с подписью мелким шрифтом «Общая справка, не медицинская рекомендация»; для 18+ — «Только для совершеннолетних». Блок «Вам может понравиться» — лента товаров из `rel` (если пусто — из той же категории, популярные).

### Корзина
- Пусто: «Корзина пуста» + кнопка «В каталог».
- Список: мини-фото, название, цена за единицу, степпер, сумма строки, «Удалить» (текстом).
- Недоступные товары (пропали из каталога или `out`) — отдельно сверху: «Эти товары сейчас недоступны» + «Убрать».
- Итого: «≈ 2 450 ₽» + подпись «Цены ориентировочные. Точную сумму оператор подтвердит при связи».
- «Возможно, будет интересно» — лента до 6 товаров (алгоритм ниже). Кнопка «+» добавляет в корзину без перехода.
- Большая кнопка «Оставить заказ» → `#/checkout`. Если `orders_enabled = false` — вместо неё плашка и кнопки связи.

### Оформление
Поля — см. `01-tz-mvp.md`. Требования:
- `<input type="tel" inputmode="tel" autocomplete="tel">`. Подсказка под полем: «С кодом страны: +7 … или +84 …». Мягкая проверка на клиенте по тем же правилам, что на сервере (`05-api.md`).
- «Как с вами связаться» — три большие кнопки-переключателя (radio): WhatsApp / Telegram / Звонок.
- Галочка 18+ — только если в корзине есть `adult`.
- Сверху свёрнутый блок «Ваш заказ: 3 товара, ≈ 2 450 ₽» (раскрывается).
- Кнопка «Отправить заказ»: при нажатии блокируется, текст «Отправляем…». Таймаут 15 с.
- Введённые телефон, имя и комнату запоминаем в `localStorage` и подставляем при следующем заказе.
- Ошибки — у полей, красным, текстом. Фокус переводится на первое ошибочное поле.

### Готово
Крупная галочка, «Заказ № N-0042 принят», `done_text`, затем «Если захотите что-то уточнить — напишите нам» + кнопки связи, кнопка «Вернуться в каталог». Корзина очищается **только после** успешного ответа.

### Ошибка отправки
«Не получилось отправить заказ. Проверьте интернет и попробуйте ещё раз.» Кнопки: «Попробовать ещё раз» (тот же `clientOrderId`) и «Отправить через WhatsApp» — открывает `https://wa.me/<цифры>?text=<текст заказа>`. Текст: «Здравствуйте! Хочу заказать:\n• Манго — 2 кг\n• Ром Chill — 1 бут.\nИтого ≈ 830 ₽\nТелефон: …\nКомната: …».

## Модули JS

| Модуль | Ответственность |
|---|---|
| `config.js` | `export const API_URL = ''`, `FALLBACK_CONTACTS`, `APP_VERSION` |
| `api.js` | `loadCatalog()` (кэш → сеть → событие обновления), `sendOrder(payload)` с таймаутом, режим заглушки |
| `store.js` | Корзина `{id: qty}` в `localStorage` (ключ `cart.v1`), кэш каталога (`catalog.v1`), профиль (`profile.v1`); подписка на изменения; все обращения в try/catch |
| `format.js` | `formatPrice(830) → "≈ 830 ₽"` (неразрывные пробелы, разделитель тысяч), `formatQty(1.5, 'кг') → "1,5 кг"`, склонения («1 товар, 2 товара, 5 товаров»), нормализация телефона |
| `recommend.js` | `suggestForCart(cart, catalog, limit=6)` |
| `app.js` | Роутер, шапка, нижняя панель, рендер экранов |
| `views/*.js` | Функции `render(container, state)` для каждого экрана. Без шаблонизаторов: `document.createElement` или шаблонные строки с обязательным экранированием |

**Всё, что пришло из таблицы, вставлять только через `textContent` или экранирование** (XSS: Саня или посторонний с доступом к таблице может ввести что угодно).

## Алгоритм «Возможно, будет интересно»

1. Кандидаты = объединение `rel` всех товаров в корзине (в порядке корзины, затем порядке `rel`).
2. Добавить `popular`.
3. Добавить товары из категорий, которых нет в корзине (по `sort`).
4. Убрать товары, которые уже в корзине, с `stock = out` и дубли. Взять первые `limit`.

Функция чистая, покрыта тестами (`tests/recommend.test.js`).

## Кэш и офлайн

- Каталог из `localStorage` показывается сразу, если он не старше 7 дней. Если старше, показываем всё равно, но с плашкой «Загружаем актуальные цены…», пока не придёт свежий.
- Нет кэша и нет сети: экран «Не удалось загрузить каталог» + «Повторить» + кнопки связи (из `FALLBACK_CONTACTS`).
- Service Worker в MVP не делаем (сложно сбрасывать кэш). PWA-манифест — на этапе 5.

## Нижняя панель корзины

Видна, если в корзине есть товары, на всех экранах, кроме корзины, оформления и «Готово». Закреплена снизу с учётом `env(safe-area-inset-bottom)`. Текст: «Корзина · 3 товара · ≈ 2 450 ₽ →».

## Доступность

Семантика (`button`, `nav`, `main`, `h1`–`h2`), `aria-label` у иконок, `aria-live="polite"` для счётчика корзины и ошибок, видимый фокус, `lang="ru"`. Масштабирование не запрещать (`user-scalable` не трогать).

## Метатеги

`<meta name="viewport" content="width=device-width, initial-scale=1">`, `theme-color`, `description`, Open Graph (`og:title`, `og:description`, `og:image`) — чтобы ссылка красиво выглядела, когда её пересылают в WhatsApp или Telegram. `<meta name="robots" content="noindex">` — сайт не нужно индексировать поисковикам (реклама только лично, см. риски).

## Режим заглушки и проверка ошибок отправки

Пока `API_URL` пуст, заказ никуда не уходит: через 0,7 с сайт отвечает успехом с номером `TEST-0001`. Сценарии ошибок включаются адресом страницы (только в режиме заглушки):

| Адрес | Что происходит при отправке |
|---|---|
| `…/?mock=error#/checkout` | обрыв сети → экран ошибки с «Попробовать ещё раз» и «Отправить через WhatsApp» |
| `…/?mock=rate` | `RATE_LIMIT` → только «Отправить через WhatsApp» |
| `…/?mock=paused` | `ORDERS_PAUSED` → форма заменяется плашкой и контактами |
| `…/?mock=unavailable` | `ITEM_UNAVAILABLE` для первого товара → он убирается из корзины |
| `…/?mock=validation` | `VALIDATION` → ошибка у поля телефона |

## Поведение оформления заказа

- Введённое в форму (кроме подтверждения 18+) сохраняется при переходах между экранами, телефон, имя, комната и способ связи запоминаются после отправки.
- Недоступные товары (нет в каталоге или «Сезон закончился») остаются в корзине отдельным блоком с кнопкой «Убрать недоступные» и в заказ не попадают.
- Повторная отправка при том же составе и телефоне использует тот же `clientOrderId`. Если состав или телефон изменились, ID новый.
- После успеха корзина очищается, адрес заменяется на `#/done/<номер>`, а «Назад» на этом экране ведёт на главную.
