# Как развернуть Apps Script (инструкция для владельца)

Всё делается в браузере на компьютере. Командная строка не нужна. Названия пунктов меню даны для русского интерфейса Google. Если интерфейс английский, в скобках указано английское название.

---

## Часть 1. Первая установка (один раз)

### Шаг 1. Создать таблицу

1. Открой https://sheets.new — создастся пустая таблица.
2. Переименуй её (клик по «Новая таблица» слева вверху), например: **«Рынок Нячанг — каталог и заказы»**.
3. **Файл → Настройки** (File → Settings) → «Часовой пояс»: **(GMT+07:00) Ho Chi Minh**. Сохранить.

### Шаг 2. Открыть редактор скриптов

1. В таблице: **Расширения → Apps Script** (Extensions → Apps Script). Откроется редактор с файлом `Код.gs` (`Code.gs`).
2. Слева вверху переименуй проект (клик по «Проект без названия»), например **«Рынок Нячанг»**.
3. Слева нажми ⚙️ **«Настройки проекта»** (Project Settings) → поставь галочку **«Показывать файл манифеста appsscript.json в редакторе»**.

### Шаг 3. Скопировать файлы из репозитория

Файлы лежат в репозитории в папке `apps-script/`. Открой каждый на GitHub → кнопка **«Copy raw file»** (значок двух квадратиков над кодом) → вставь в редактор.

1. **`appsscript.json`**: открой его в редакторе (слева, в списке файлов), выдели всё (Ctrl+A), вставь содержимое из репозитория.
2. **Файл `Код.gs`**: переименуй (три точки рядом с названием → «Переименовать») в `Main` и вставь содержимое `Main.gs`.
3. Для каждого остального `.gs` файла: **«+» рядом с «Файлы» → «Скрипт»** → введи имя **без `.gs`** (например `Catalog`) → вставь содержимое.
4. Нажми 💾 (или Ctrl+S). Если редактор подсветил ошибку — проверь, что файл скопирован целиком.

Список файлов в редакторе должен совпадать со списком в `apps-script/`.

### Шаг 4. Первый запуск `setup` и разрешения

1. Вверху редактора в выпадающем списке функций выбери **`setup`** → **«Выполнить»** (Run).
2. Появится «Требуется авторизация» → **«Проверить разрешения»** → выбери свой аккаунт.
3. Появится экран **«Приложение не проверено Google»** — это нормально для своего скрипта. Нажми **«Дополнительные настройки»** (Advanced) → **«Перейти на страницу „Рынок Нячанг“ (небезопасно)»** → **«Разрешить»** (Allow). Если есть галочки — поставь все.
4. Дождись в журнале выполнения «Выполнение завершено». Вернись в таблицу: появятся листы, меню **«🛒 Рынок»** и окно со сводкой.

### Шаг 5. Создать Telegram-бота

1. В Telegram открой **@BotFather** → `/newbot` → придумай имя (например «Рынок у отеля — заказы») и логин, оканчивающийся на `bot`.
2. BotFather пришлёт **токен** вида `123456789:AA...`. Никому его не показывай и не клади в репозиторий.
3. Саня (и ты, если хочешь тоже получать заказы) открывает бота по ссылке от BotFather и нажимает **«Старт»** / пишет любое сообщение.

### Шаг 6. Script Properties (секреты)

1. Редактор → ⚙️ **«Настройки проекта»** → внизу **«Свойства скрипта»** (Script Properties) → **«Изменить свойства скрипта»** → «Добавить свойство».
2. Добавь:
   - `TELEGRAM_BOT_TOKEN` = токен из шага 5;
   - `ALERT_EMAIL` = твоя почта.
3. Сохрани.
4. В таблице: **🛒 Рынок → Найти chat_id Telegram**. Покажутся chat_id тех, кто написал боту. Скопируй нужные.
5. Добавь свойство `TELEGRAM_CHAT_IDS` = chat_id через запятую (например `111111111,222222222`). Сохрани.
6. **🛒 Рынок → Отправить тестовое уведомление** — в Telegram должно прийти сообщение.

### Шаг 7. Развернуть веб-приложение

1. Редактор → синяя кнопка **«Начать развертывание» → «Новое развертывание»** (Deploy → New deployment).
2. Значок ⚙️ рядом с «Выберите тип» → **«Веб-приложение»** (Web app).
3. Описание: `v1`. **«Запуск от имени»: «Я (твоя почта)»** (Execute as: Me). **«У кого есть доступ»: «Все»** (Anyone). Не «Все с аккаунтом Google» — у гостей может не быть аккаунта.
4. **«Развернуть»**. Если попросит разрешения — разреши, как в шаге 4.
5. Скопируй **URL веб-приложения** (оканчивается на `/exec`).
6. Проверка: открой в браузере `<URL>?action=ping` — должно показаться `{"ok":true,...}`. Затем `<URL>?action=catalog` — JSON каталога.
7. **Пришли этот URL в сессию Claude Code** со словами «впиши API_URL». Claude пропишет его в `site/config.js` и опубликует сайт. URL не секретный — он всё равно виден в коде сайта.

### Шаг 8. Доступ для Сани

1. Таблица → **«Настройки доступа»** (Share) → добавь почту Сани → роль **«Редактор»**. Галочку «Уведомить» можно оставить.
2. Папка «Фото товаров» (ссылка есть в окне после `setup` и в «Ошибках»/сводке) — доступ Сане как редактору. Доступ «все, у кого есть ссылка — читатель» `setup` уже включил.
3. Саня ставит на телефон приложения **Google Таблицы** и **Google Диск**. Дальше — `12-operator-guide.md`.

## Часть 2. Обновление кода (каждый раз, когда Claude поменял `apps-script/`)

Claude в каждом отчёте пишет раздел **«Как развернуть»** — следуй ему. Общая схема:

1. Открой таблицу → **Расширения → Apps Script**.
2. Замени содержимое изменённых файлов (и добавь новые) — так же, как в шаге 3. Сохрани.
3. Если в «Как развернуть» сказано запустить `setup` или другую функцию — выбери её и нажми «Выполнить». Если просит разрешения — разреши.
4. Если сказано добавить Script Property — добавь (шаг 6).
5. **Опубликуй новую версию в том же развертывании:**
   **«Начать развертывание» → «Управление развертываниями»** (Manage deployments) → выбери активное развертывание → **✏️ карандаш** → «Версия»: **«Новая версия»** → **«Развернуть»**.
   URL остаётся прежним, сайт трогать не нужно.
6. Проверь `<URL>?action=ping`.

> ⚠️ **Не нажимай «Новое развертывание»** для обновлений — получится новый URL, и сайт продолжит ходить на старую версию.
>
> Изменения в коде **без** шага 5 на сайт не попадают: веб-приложение работает на зафиксированной версии. Меню и триггеры в таблице при этом используют свежий код сразу.

## Часть 3. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| `?action=ping` просит войти в Google или пишет «нет доступа» | В развертывании «У кого есть доступ» должно быть «Все» (Anyone). Изменить: Управление развертываниями → карандаш |
| Сайт показывает старые цены | Подожди 5 минут или 🛒 Рынок → Обновить сайт сейчас |
| Исправил код, а на сайте ничего не поменялось | Не сделан шаг 5 части 2 (новая версия развертывания) |
| Не приходят уведомления | 🛒 Рынок → Отправить тестовое уведомление. Проверь `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_IDS` и что получатель нажал «Старт» у бота. Смотри лист «Ошибки» |
| Ошибка «Exception: You do not have permission…» | Запусти любую функцию из редактора — Google заново спросит разрешения |
| Фото не появляются | Имя файла = ID товара (`fr-001.jpg`). 🛒 Рынок → Подтянуть фото. Проверь лист «Ошибки» |
| Ошибки при выполнении | Редактор → слева ☰ **«Выполнения»** (Executions) — там журнал каждого запуска с текстом ошибки. Скопируй его в сессию Claude |

## Часть 4. Резервная копия

Раз в месяц (или перед крупными изменениями): таблица → **Файл → Создать копию**. Код и так хранится в репозитории.
