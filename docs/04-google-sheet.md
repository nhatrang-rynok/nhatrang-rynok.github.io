# Google Таблица: структура

Одна таблица, например «Рынок Нячанг — каталог и заказы». Скрипт к ней привязан (Расширения → Apps Script). Все листы, заголовки, проверки данных и выпадающие списки создаёт функция `setup()` — вручную ничего размечать не нужно.

**Важно:** сервер ищет колонки **по тексту заголовка** в первой строке, а не по позиции. Колонки можно переставлять и добавлять свои, но **нельзя переименовывать заголовки**, перечисленные ниже. Первая строка закреплена и защищена от случайной правки (защита с предупреждением).

## Лист «Товары»

| Заголовок | Ключ в JSON | Тип | Обяз. | Описание |
|---|---|---|---|---|
| `ID` | `id` | текст | да | Уникальный, латиница, цифры и дефис: `fr-001`, `al-003`. Префикс по категории. **После публикации не менять** — по нему работают корзины гостей и статистика |
| `Показывать` | — | флажок | да | Снят → товара нет на сайте |
| `Категория` | `cat` | список | да | ID из листа «Категории» (выпадающий список) |
| `Название` | `name` | текст | да | До 60 символов |
| `Коротко` | `short` | текст | нет | Одна строка под названием в списке, до 80 символов: «Сладкий, без косточек» |
| `Описание` | `desc` | текст | нет | До 600 символов. Переносы строк сохраняются |
| `Цена ₫` | — | число | нет | Цена в донгах (за единицу) |
| `Цена ₽` | `price` | число | * | Цена в рублях. Если пусто — считается из `Цена ₫` по курсу. *Нужна хотя бы одна из двух цен |
| `Единица` | `unit` | текст | да | `кг`, `шт`, `бут. 0,7 л`, `упак. 500 г` |
| `Шаг` | `step` | число | нет | Шаг количества: `1` (по умолчанию) или `0.5` для кг |
| `Минимум` | `min` | число | нет | Минимальное количество, по умолчанию = шаг |
| `Фото` | `img` | текст | нет | ID файла на Диске или ссылка. Заполняется автоматически синхронизацией фото |
| `Предупреждения` | `warn` | текст | нет | Общая справка (аллергия и т. п.). Шаблоны — `11-warnings-and-legal.md` |
| `Где куплено` | `src` | текст | нет | «Рынок Чо Дам», «Аптека Long Châu» — показываем гостю для доверия |
| `18+` | `adult` | флажок | нет | Алкоголь. Включает отметку и обязательную галочку в форме |
| `Хит` | — | флажок | нет | Ручное попадание в «Самое популярное» (идёт первым) |
| `Похожие` | `rel` | текст | нет | ID через запятую: `fr-002, sw-005`. Для «Вам может понравиться» и рекомендаций в корзине |
| `Наличие` | `stock` | список | нет | `В наличии` (по умолчанию) / `Под заказ` / `Сезон закончился`. При «Сезон закончился» товар показывается серым, в корзину не добавляется |
| `Порядок` | `sort` | число | нет | Сортировка внутри категории, меньше = выше. Пусто = в конец, по названию |
| `Обновлено` | — | дата | авто | Ставит триггер `onEdit` |

Цена в рублях при расчёте из донгов: `ceil(Цена ₫ / Курс / Округление) × Округление`. Например 85 000 ₫ / 300 = 283,3 → при округлении 10 получается 290 ₽.

### Правила валидации строки (на сервере)

Строка пропускается и попадает в лист «Ошибки», если: пустой или дублирующийся `ID`; ID не по шаблону `^[a-z0-9-]{2,20}$`; категория не существует или выключена; нет цены; цена ≤ 0. Остальные кривые значения (шаг, минимум, неизвестные ID в «Похожих») молча заменяются значениями по умолчанию или отбрасываются.

## Лист «Категории»

| Заголовок | Ключ | Описание |
|---|---|---|
| `ID` | `id` | `fruits`, `alcohol`, `sweets`, `coffee`, `souvenirs`, `pharmacy` |
| `Показывать` | — | флажок |
| `Название` | `name` | «Фрукты», «Ром и алкоголь», «Сладости», «Кофе», «Сувениры», «Аптека» |
| `Иконка` | `icon` | Эмодзи: 🥭 🥃 🍬 ☕ 🎁 💊 |
| `Подпись` | `note` | Необязательная строка под заголовком категории. Для аптеки: «Обычные безрецептурные товары из аптеки. Перед применением прочитайте инструкцию» |
| `Порядок` | `sort` | число |

Начальные данные создаёт `setup()`: все 6 категорий, но «Показывать» включено только у `fruits` и `alcohol`.

## Лист «Настройки»

Две колонки: `Ключ` | `Значение` (+ третья `Пояснение` для Сани). Колонка `Публично` (флажок) определяет, уходит ли значение на сайт.

| Ключ | Пример | Публично | Пояснение |
|---|---|---|---|
| `site_title` | Рынок у отеля | да | Название в шапке сайта |
| `phone` | +84 000 000 000 | да | Телефон для звонка |
| `whatsapp` | +84 000 000 000 | да | Номер WhatsApp (цифры, с кодом страны) |
| `telegram` | primer_operator | да | Ник в Telegram без @ |
| `orders_enabled` | TRUE | да | Флажок «Принимаем заказы» |
| `announcement` | | да | Объявление на главной (пусто = нет) |
| `terms` | | да | Условия (доставка, оплата). Пусто = блок скрыт |
| `done_text` | С вами свяжутся по поводу заказа на оставленный контактный телефон. Ожидайте. | да | Текст на экране «Готово» |
| `rate_vnd_per_rub` | 300 | нет | Курс: сколько донгов в 1 рубле |
| `rub_rounding` | 10 | нет | Округление рублёвых цен вверх |
| `popular_days` | 30 | нет | За сколько дней считать популярное |
| `popular_count` | 8 | нет | Сколько товаров в блоке «Самое популярное» |

## Лист «Заказы»

Пишет только скрипт. Саня меняет только `Статус` и `Заметки`.

| Заголовок | Описание |
|---|---|
| `Номер` | `N-0042` |
| `Создан` | Дата и время (часовой пояс Asia/Ho_Chi_Minh) |
| `Статус` | Список: `Новый` (по умолчанию) / `Связались` / `Закуплено` / `Доставлено` / `Отменён`. Цвет строки зависит от статуса (условное форматирование) |
| `Телефон` | Нормализованный: `+79990000000` |
| `Связь` | WhatsApp / Telegram / Звонок |
| `Имя` | |
| `Комната` | |
| `Комментарий` | |
| `Состав` | Текстом: «Манго — 2 кг × 90 ₽ = 180 ₽; Ром Chill — 1 бут. × 650 ₽ = 650 ₽» |
| `Сумма ₽` | Число, пересчитанное сервером |
| `18+ подтверждено` | флажок |
| `Уведомление` | `ok` / `ошибка: …` |
| `ID клиента` | `clientOrderId`, для отладки дублей |
| `Заметки` | Для Сани |

## Лист «Позиции заказов»

Нужен для статистики «Самое популярное». Пишет только скрипт.

`Номер заказа` | `Создан` | `ID товара` | `Название` | `Кол-во` | `Цена ₽` | `Сумма ₽` | `Отменён` (формула или флажок, который скрипт ставит при статусе «Отменён» — этап 4)

## Лист «Ошибки»

`Когда` | `Где` | `Что` — пишет скрипт: битые строки товаров, ошибки Telegram, исключения. Хранятся последние 500 строк.

## Лист «Кандидаты» (этап 3, для сбора контента)

`Название` | `Категория` | `Сколько роликов упомянули` | `Цитата` | `Берём?` (Да/Нет/Позже) | `Цена закупки ₫` | `Где купить` | `Комментарий Сани` — см. `10-content-pipeline.md`.

## Доступы

- Таблица: владелец — владелец, Саня — редактор. Больше никому.
- Папка, где лежит таблица, и сама таблица: **ограниченный доступ** (только владелец и Саня). В таблице телефоны гостей, публичной ссылки быть не должно.
- Папка «Фото товаров» (подпапка той, где таблица): владелец и Саня — редакторы; «все, у кого есть ссылка» — читатели (нужно для показа фото на сайте). Публичной должна быть только она.
